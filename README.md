# 📰 TechNews Today

## 📱 Portal de Notícias de Tecnologia

O **TechNews Today** é um portal de notícias sobre tecnologia desenvolvido como atividade da aula de HTML e CSS.

O projeto apresenta um layout moderno e responsivo, utilizando recursos de HTML5 e CSS3 para criar uma experiência visual semelhante a um portal tecnológico.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Recursos do projeto

- Estrutura semântica com HTML5
- Header com efeito Glassmorphism
- Título com gradiente
- Layout utilizando CSS Grid
- Seção de notícia em destaque
- Vídeo incorporado
- Formulário de inscrição para newsletter
- Campo de e-mail
- Seleção de área de interesse
- Checkbox de aceite dos termos
- Botão de inscrição
- Rodapé com informações de contato
- Design responsivo para dispositivos móveis
- Efeitos de hover
- Elemento `details` e `summary` para a opção "Leia mais"
